# شکاف داده و گام‌های بعدی

## شکاف‌های بحرانی

یک صحنه واقعی Sentinel-2 L2A کم‌ابر برای AOI موقت بازیابی، بریده و checksum شده است (`outputs/validation/sentinel2_scene_manifest.json`). این صحنه هنوز وارد استخراج شاخص یا مدل نشده است. نقشهٔ رسمی GIS ورقهٔ ۶۸۴۸، نمونه‌های ژئوشیمی با QA/QC، ژئوفیزیک محلی، خروجی تاریخ‌دار کاداستر و برچسب‌های آزمون مستقل هنوز موجود نیستند. مشتقات ASTER GDEM نیز توپوگرافی هستند، نه مدرک کانه‌زایی. نبود داده و آزمون مستقل اجازهٔ ادعای دقت ۸۰٪ نمی‌دهد.

## اولویت پیشنهادی

ابتدا باید لایه رسمی زمین‌شناسی و وضعیت حقوقی محدوده‌ها اخذ شود. سپس برای مدل منگنز در بلوک‌های دارای مجوز نمونه‌برداری طراحی شود. مدل کرومیت باید با نقشه اولترامافیک و مختصات مستقل رخدادهای کرومیت ساخته شود. مدل آهن فقط پس از تعیین محدوده و داده مکانی معتبر آغاز شود.
