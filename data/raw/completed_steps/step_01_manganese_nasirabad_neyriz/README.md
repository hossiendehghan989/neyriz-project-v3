# بسته داده استپ ۱: منگنز نصیرآباد–نیریز

این بسته فقط برای استپ ۱ تهیه شده است. یک رخداد منگنز دارای مختصات قابل راستی‌آزمایی در محدوده نصیرآباد ثبت شده است. گزارش تفصیلی و منابع در `report_step01_manganese_nasirabad_neyriz.md` قرار دارد.

| فایل | محتوا |
|---|---|
| `manganese_confirmed_step01.geojson` | لایه نقطه‌ای قطعی با یک رخداد منگنز، WGS 84 / EPSG:4326 |
| `manganese_confirmed_step01.csv` | همان داده در قالب CSV UTF-8-SIG |
| `manganese_screened_not_geocoded_step01.csv` | موارد گزارش‌شده اما فاقد مختصات؛ فقط برای پی‌گیری |
| `sources_step01.csv` | فراداده و پیوند منابع |
| `report_step01_manganese_nasirabad_neyriz.md` | نتیجه، روش گزینش، محدودیت‌ها و مراجع |

**کنترل کیفیت:** مختصات منگنز نصیرآباد از `29°10′N, 54°14′E` به `29.166667, 54.233333` تبدیل شده است. فاصله با نقطه مرجع روستای نصیرآباد (`29°14′N, 54°15′E`) با فرمول Haversine برابر 7.59 کیلومتر است.
