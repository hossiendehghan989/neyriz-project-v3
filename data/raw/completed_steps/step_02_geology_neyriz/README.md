# بسته استپ ۲ — نقشه زمین‌شناسی نیریز و واحدهای میزبان

فایل اصلی: `host_lithology_units.geojson`. این لایه شامل چرت رادیولاریتی/زون پیچکان و مجموعه افیولیتی نیریز به‌صورت پلیگان‌های غربالگری با `precision_class=B` است. مرزها از GIS رسمی رقومی‌سازی نشده‌اند و باید پس از دریافت نسخه رسمی نقشه جایگزین شوند.

> **تصویر معتبر از ورقه ۶۸۴۸ نیریز یافت نشد.**

تصویر نامرتبط گل‌گهر از بسته حذف شده است. فایل GeoJSON به‌دلیل اتکا به مختصات رخداد و توصیف‌های منابع استپ ۱ نگه داشته شده و به تصویر حذف‌شده وابسته نیست.
